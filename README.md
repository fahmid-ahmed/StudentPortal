\##Project Description 

The Student Management System is a terminal-based application developed to manage and organize student information, 

including academic details such as student ID, name, age, CGPA, department, semester, and completed credit hours, 

as well as personal and contact information like email, international phone number, and residential address.

The system also keeps track of student statuses such as active, inactive, and graduated. Along with managing student records,

the project provides practical experience with an industry-standard Git workflow by using feature branches, documentation files,

commits, and pull requests, allowing team members to work collaboratively and combine their changes through peer-reviewed 

pull requests.
