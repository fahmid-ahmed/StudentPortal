## Project Description
Student Management System is a comprehensive terminal-based application designed to manage student academic records, personal information, and enrollment details while serving as a practical environment to implement industry-standard Git workflow management. The system efficiently tracks core academic metrics such as student IDs, full names, age, CGPA, departments, semesters, and completed credit hours, while maintaining up-to-date contact records including emails, international phone numbers, and residential addresses. Built collaboratively using structured feature branches, documentation logs, and peer-reviewed pull requests, it provides a scalable architecture for monitoring active, inactive, and graduated student statuses.
